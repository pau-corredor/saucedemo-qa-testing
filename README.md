# SauceDemo QA Testing

Manual QA project on https://www.saucedemo.com

## Objetivo
Diseñar y ejecutar un plan de pruebas y casos manuales sobre una tienda
en línea de demostración, gestionando el trabajo con Kanban en Jira.

## Contenido
- `docs/`: plan de pruebas, mapa de funcionalidades, lista de riesgos
- `test-cases/`: casos de prueba manuales
- `bug-reports/`: reportes de defectos
- `evidence/`: capturas y videos

## Estado
En progreso (semana 1: preparación y plan de pruebas).
